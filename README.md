# Hospital-Analytics-Dashboard



Objective

Analyze hospital operations data to understand patient distribution, diagnose trends, and evaluate performance indicators such as length of stay and billing.

 Tools
 Power BI
 Dax

Key Insights

High-risk cases drive the highest revenue impact. 
• Patients aged 41–60 show the longest length of stay. 
• Revenue distribution highlights the financial effect of insurance categories. 
• Gender distribution remains balanced across admissions
